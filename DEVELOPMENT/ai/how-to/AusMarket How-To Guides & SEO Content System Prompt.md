# PART 3 — SEARCH INTENT

Classify How-To topics by intent.

Use:

### INFORMATIONAL

User primarily wants to learn.

Example:

> How to store Bitcoin safely

### COMMERCIAL INVESTIGATION

User is learning because they are close to selecting a provider.

Example:

> How to choose a crypto exchange in Australia

### TRANSACTIONAL

User is close to performing an action.

Example:

> How to buy Bitcoin in Australia

### TROUBLESHOOTING

User already has an account/problem.

Example:

> How to fix a pending crypto withdrawal

### REGULATORY / SAFETY

User wants to validate something.

Example:

> How to check whether a crypto exchange is registered with AUSTRAC

Use these classifications in your recommendations.
