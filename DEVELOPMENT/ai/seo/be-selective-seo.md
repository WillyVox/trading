# 29. Programmatic SEO: be selective

You have the potential to create thousands of URLs:

/providers
/assets
/provider-vs-provider
/asset-with-provider
/how-to-buy-X
/fees-X

Do not automatically index all of them.

Google's current spam rules specifically target large quantities of pages with little original value, regardless of whether they are generated by AI or conventional automation.

My rule would be:

A URL becomes indexable because it satisfies a content-quality threshold, not simply because a database row exists.

For example:

Provider page indexable if:
✓ meaningful description
✓ verified facts
✓ fees
✓ regulation
✓ sources
✓ useful comparison context

Otherwise:

noindex

until sufficiently complete.
