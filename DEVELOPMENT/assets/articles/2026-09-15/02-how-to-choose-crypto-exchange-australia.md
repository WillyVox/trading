```{=html}
<p>
```

Choosing a crypto exchange is not just about finding the lowest number
on a fee page. A beginner also needs to know whether the provider can be
checked, how Australian dollars move in and out, what the chosen
transaction costs and what happens when crypto is withdrawn.

```{=html}
</p>
```

```{=html}
<h2>
```

1.  Check the provider first
    ```{=html}
    </h2>
    ```
    ```{=html}
    <p>
    ```
    Start with the exact legal or trading name. AUSTRAC's public Virtual
    Asset Service Provider register lets Australians search registered
    providers. Treat this as one verification step, not an endorsement
    or guarantee of returns.
    ```{=html}
    </p>
    ```

```{=html}
<h2>
```

2.  Compare the transaction you will actually make
    ```{=html}
    </h2>
    ```
    ```{=html}
    <p>
    ```
    An exchange may offer both an instant-buy interface and an
    order-book product. They can have different pricing. Comparing one
    provider's order-book fee with another provider's instant-buy cost
    is not like-for-like.
    ```{=html}
    </p>
    ```

```{=html}
<h2>
```

3.  Check how AUD moves in and out
    ```{=html}
    </h2>
    ```
    ```{=html}
    <p>
    ```
    Look at the deposit method you use --- such as PayID, bank transfer
    or card --- and check current fees and limits. Check withdrawals as
    well.
    ```{=html}
    </p>
    ```

```{=html}
<h2>
```

4.  Check assets and tools you actually need
    ```{=html}
    </h2>
    ```
    ```{=html}
    <p>
    ```
    A huge coin list is not automatically better. If you only want to
    research major assets, hundreds of extra tokens may add little
    value. Confirm any order types, recurring purchases or other
    features you expect to use.
    ```{=html}
    </p>
    ```

```{=html}
<h2>
```

5.  Review security and withdrawal controls
    ```{=html}
    </h2>
    ```
    ```{=html}
    <p>
    ```
    Look for practical account protections such as two-factor
    authentication. Confirm how crypto and AUD can be withdrawn before
    depositing money.
    ```{=html}
    </p>
    ```
