```{=html}
<p>
```

Buying crypto for the first time can look more complicated than it needs
to be. The basic journey is straightforward: understand the risk, choose
a platform, verify your account, move Australian dollars in, review the
transaction and buy. The important part is slowing down where fees,
security and provider legitimacy can differ.

```{=html}
</p>
```

```{=html}
<h2>
```

Before you start: understand the risk

```{=html}
</h2>
```

```{=html}
<p>
```

Crypto is a high-risk, volatile asset class. Prices can move quickly and
there is no guarantee that a coin will rise in value. Treat a first
purchase as a learning process rather than a promise of profit, and do
not use money you need for essential expenses.

```{=html}
</p>
```

```{=html}
<h2>
```

Step 1: choose an exchange

```{=html}
</h2>
```

```{=html}
<p>
```

Do not choose only because an influencer mentioned a platform or because
its homepage advertises one low fee. Compare AUD deposits and
withdrawals, transaction costs, supported assets, security controls and
current Australian registration information.

```{=html}
</p>
```

```{=html}
<p>
```

Start with our `<a href="/compare/crypto-exchanges">`{=html}crypto
exchange comparison`</a>`{=html}, then inspect the provider profile and
its sources.

```{=html}
</p>
```

```{=html}
<h2>
```

Step 2: check the provider

```{=html}
</h2>
```

```{=html}
<p>
```

Confirm that you are using the real website or official app. AUSTRAC now
provides a public Virtual Asset Service Provider register that can be
used to check whether a provider is registered. Registration is useful
information, but it is not a guarantee that an investment is safe or
profitable.

```{=html}
</p>
```

```{=html}
<h2>
```

Step 3: create and verify your account

```{=html}
</h2>
```

```{=html}
<p>
```

Follow the provider's own identity-verification instructions. Never send
identity documents through an unsolicited social-media message or a link
sent by a stranger.

```{=html}
</p>
```

```{=html}
<h2>
```

Step 4: deposit AUD

```{=html}
</h2>
```

```{=html}
<p>
```

Check the funding method you will actually use. Bank transfer or PayID
can be priced differently from card funding. Check fees and limits
before sending money.

```{=html}
</p>
```

```{=html}
<h2>
```

Step 5: choose how you will buy

```{=html}
</h2>
```

```{=html}
<p>
```

Some exchanges offer both a simple instant-buy screen and an order-book
or markets interface. These can have different pricing. Before
confirming, check the amount of crypto you will receive, the quoted
price and any displayed fee.

```{=html}
</p>
```

Step 7: keep records and learn what happens next

```{=html}
<p>
```
